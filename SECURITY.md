# Security

Please report security issues privately, never in a public issue:

- use GitHub's **Report a vulnerability** button in the Security tab of this repository, or
- email support@jointhestudentlife.com with "Security" in the subject.

Include what you found, how to reproduce it and which version you used. We will reply by email.

This repository is an SDK for the public, read only API at https://jointhestudentlife.com (docs: https://jointhestudentlife.com/developers). The API needs no key, so the SDK holds no credentials.
